# Лабораторна робота №5: Використання SFML в C++ проєкті
**Виконав:** Береговий Дмитро Андрійович  
**Варіант 1:** Моделювання руху автомобіля (розгін та гальмування)
## Опис проєкту
Програма моделює прямолінійний рух автомобіля масою 1200кг під дією сили тяги двигуна, сили опору руху та сили гальмування з використанням чисельного методу Ейлера та кроку часу.
Візуалізація реалізована засобами бібліотеки SFML.

## Стек технологій
* **Мова:** C++17
* **Графічна бібліотека:** SFML (Graphics, Window, System)
* **Пакетний менеджер:** vcpkg (режим маніфесту)
* **Система збирання:** CMake

## Керування у симуляції
* `Space` — натиснути педаль газу (розгін)
* `B` — натиснути педаль гальма
* `Вгору / Вниз` — збільшити / зменшити силу тяги
* `Вліво / Вправо` — зменшити / зменшити силу гальмування
* `P` — пауза / продовження симуляції
* `R` — скидання параметрів у початковий стан
